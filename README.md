# The Cocktail API

Una página web simple que muestra distintos tipos de bebidas usando la API pública de TheCocktailDB. Permite a los usuarios descubrir bebidas alcohólicas, no alcohólicas y recibir una sugerencia aleatoria.

## 🚀 Características

- Mostrar listado de bebidas alcohólicas.
- Mostrar listado de bebidas no alcohólicas.
- Obtener una bebida aleatoria al instante.
- Diseño sencillo y amigable para el usuario (frontend puro).
- Código modular y organizado.

## 🛠️ Estructura del Proyecto

- `index.html`: Estructura principal de la página.
- `style.css`: Estilos para la apariencia de la página.
- `icons/`
  - `GitHubLogo.svg`: Logotipo utilizado en el pie de página.
- `scrpit/`
  - `alcoholic.js`: Maneja la visualización de bebidas alcohólicas.
  - `non-alcoholic.js`: Maneja la visualización de bebidas no alcohólicas.
  - `random.js`: Muestra una bebida aleatoria.
  - `header.js`: Renderiza el encabezado de la página.
  - `footer.js`: Renderiza el pie de página y logotipo de GitHub.

## 📦 Instalación

1. Clona este repositorio en tu máquina local:
2. git clone https://github.com/crigca/The_cocktail_API.git

text

## 💻 Uso

1. Selecciona si quieres ver bebidas alcohólicas, no alcohólicas o una bebida aleatoria.
2. Explora la información y los ingredientes de cada bebida.
3. Puedes modificar y reutilizar los scripts para ampliar funcionalidades.
